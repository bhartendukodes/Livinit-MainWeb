# Livinit - Main Web Application

The primary web application for the Livinit platform, built with TypeScript for a robust and type-safe frontend experience.

## Features

- Modern TypeScript web application
- Responsive design
- User authentication and management
- Integration with Livinit backend services
- Component-based architecture

## Tech Stack

- **Language:** TypeScript
- **UI:** Component-based architecture
- **Styling:** Modern CSS

## Getting Started

1. Clone the repository
```
git clone https://github.com/bhartendukodes/Livinit-MainWeb.git
cd Livinit-MainWeb
```
2. Install dependencies
```
npm install
```
3. Run development server
```
npm run dev
```
